# Full Dashboard Example

This larger example is a multi-file LHT app-style document. It is intentionally broad rather than tiny:

- conditional resources and logical image definitions
- block, row, flow, scrollbox, overlay, table, canvas
- inline content, lists, links, headings, stateful classes
- inputs, buttons, event handlers, lifecycle events, `onError`
- storage and session
- `Request` callbacks
- static isolated libraries
- dynamic cross-origin library loading with `integrity`
- drawing-only canvas capability passed into a library

Files:

- `index.lht` - the document
- `scripts/app.ls` - page behavior
- `lib/format.ls` - isolated formatting helpers
- `lib/charts.ls` - isolated chart drawing helpers

External URLs and image resources are illustrative placeholders.
