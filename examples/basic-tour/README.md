# Basic Tour Example

`index.lht` is a compact single-file LHT document that demonstrates the core authoring surface:

- document metadata
- inline style declarations
- constants and classes
- logical image definitions
- block, row, flow, table, and text-hosting content
- inline text modifiers and links
- lists
- input/button events
- storage
- `document.on("error", ...)`

The referenced `/assets/ui-basic.gif` is intentionally a logical placeholder. It shows how a real document would bind an atlas resource without requiring this example directory to ship binary assets.
